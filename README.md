# MikuMikuImport

MikuMikuImport 是一款面向 Blender 的 MMD 风格化渲染插件，帮助用户快速加载、管理和调整渲染预设，提升角色渲染效率与一致性。

它适合用于 MMD/二次元风格角色渲染、人物设定效果复现，以及批量创建统一视觉风格的场景。

## 功能特点

- 快速加载风格化渲染预设
- 支持自定义制作和保存渲染预设
- 自动生成描边效果
- 提供更接近 MMD 的渲染风格

## 适用场景

- 角色渲染
- 二次元风格呈现
- MMD 风格作品复刻
- 批量统一渲染参数

## 安装方式

1. 下载本仓库中的插件压缩包或对应版本目录
2. 打开 Blender
3. 进入 编辑 > 偏好设置 > 插件
4. 选择 从磁盘安装
5. 选择插件目录或压缩包，完成安装

## 使用方法

1. 在 Blender 中启用插件
2. 选择需要使用的渲染预设
3. 调整材质、光照和后期参数
4. 生成最终渲染结果
